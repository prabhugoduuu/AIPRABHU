# Prabhu - AI assistant for Android

Chat app with side menu, chat history (search, rename, delete), photo/PDF/Word/text attach,
voice input and "Hey Prabhu". Works as a normal chat AI; voice is optional.
Add any number of AI APIs inside the app (Claude, Gemini, OpenAI, Groq, OpenRouter or custom).

v2.1: new chat dashboard - greeting + quick-start cards, avatars, copy / listen / share / retry
on every answer, typing indicator, mic/send toggle, grouped chat history, italic/quote markdown.

Build: push to GitHub -> Actions -> "Build APK" -> download "Prabhu-APK".
Keys stay on the phone.
